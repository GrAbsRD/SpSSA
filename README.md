# SpSSA (Symplectic Singular Spectrum Analysis): a novel approach for mode decomposition of time series 
The MATLAB/Octave Code is for the following papers:
- Hong-Yan Zhang,  et. al.,  **Symplectic Singular Spectrum Analysis with Arbitrary Time Delays: Signal Reconstruction and Boundary Artifact Mitigation**, submitted to  **Results In Engineering**
- Hong-Yan Zhang, et. al., **A Correction for the Paper "Symplectic geometry mode decomposition and its application to rotating machinery compound fault diagnosis"**, arXiv:2508.20990 [eess.SP]
- Hong-Yan Zhang, et. al., **Pulling Back Theorem for Generalizing the Diagonal Averaging Principle in Symplectic Geometry Mode Decomposition and Singular Spectrum Analysis**,  arXiv:2503.09584 [eess.SP]
